# Openvas_lab1-project
Scanning with openvas 
This report documents an issue encountered with the OpenVAS vulnerability scanner, in which the vulnerability database and/or scanner feed is not updating as expected. OpenVAS relies on regularly updated vulnerability tests and security feeds to identify known vulnerabilities accurately during security assessments.
The OpenVAS scanner is experiencing difficulties updating its vulnerability feeds. As a result, the scanner  continue using outdated vulnerability definitions, potentially affecting the accuracy and reliability of vulnerability assessments.which causes the ipconfiguration not been able to work properly and not scanning 
Possible Causes
The issue may be caused by one or more of the following:
Network connectivity problems preventing access to update servers.
DNS resolution failures.
Incorrect feed synchronization or configuration.
Permission issues affecting feed files or update processes.
Feed synchronization services failing or becoming stuck.
Proxy, firewall, or repository access restrictions.
